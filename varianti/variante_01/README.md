# Variante 01 - apertura scorrevole

**Tavola:** A-02  
**Stato:** superata dalla variante 02, conservata come alternativa

Questa variante prevede un unico pannello vetrato che scorre sopra il piano di copertura lungo i 93 cm. L'apertura risultante è di 120 × 93 cm.
